# Personal Mini-Toolkit

## Project Title
Personal Mini-Toolkit

## What This Toolkit Does
This Python program is a menu-driven utility hub that provides three interactive tools:
1. **Quick To-Do List Manager:** Lets users view, dynamically add, and remove tasks on the fly using a Python list.
2. **Tip & Split Calculator:** Quickly calculates restaurant tips and splits total costs evenly among groups.
3. **Guess the Number Game:** An engaging guessing game utilizing loops and conditional logic to provide high/low hints.

## How to Run It
1. Make sure you have Python installed on your system.
2. Download or clone this repository.
3. Open your terminal or command prompt inside the project folder and run:
   ```bash
   python toolkit.py
